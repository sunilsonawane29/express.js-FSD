GET /users with ?fields Projection

Filter which fields the API returns (e.g. ?fields=name,email)

POST /users - Create Single User

Validates required fields, checks for duplicate email, and returns 201 Created.

POST /users/bulk - Add Multiple Users

Processes an array of users and returns exactly which users were added and which were rejected with specific reasons (duplicate emails, format errors, etc.).

DELETE /users - Multiple Users Removal

Removes users by passing an array of IDs in request body (e.g. [1, 2, 3] or {"ids": [1, 2]}).

💡 Tip: You can also select rows in the user table on the right and click "Delete Selected".
